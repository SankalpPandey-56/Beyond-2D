Project: Beyond-2D

Automated 2D Floor Plan to Interactive 3D Model Conversion using Gemma 4
Role Lead Architect / Evaluator
Time Limit 6–7 Hours Maximum
AI Engine Gemma 4 Multimodal (AI Studio)
Status Approved (With Scope Cuts)
EXECUTIVE VERDICT: FEASIBLE WITH TARGETED ARCHITECTURE PIVOT

Beyond-2D can realistically be built and demonstrated within 6–7 hours, provided the team adopts the Semantic Room-Box Topological Extrusion pattern. If attempted using unconstrained vector line tracing and Three.js boolean CSG (cutting holes in walls), project failure probability is >90%.

1 Technical Feasibility Analysis

Each step of the proposed end-to-end workflow has been stress-tested against the 6–7 hour timeline:

Workflow Step Complexity Feasibility Key Pitfalls & Failure Modes
1. Frontend Upload Low High (45m) Dropzone, image preview, progress state. Failure risk is minimal if single-page Next.js is used.
2. AI Floor-Plan Parsing High Medium (1.2h) VLMs excel at semantic recognition (identifying rooms), but struggle with sub-pixel Euclidean precision. Asking for unconstrained vector lines produces overlapping, non-orthogonal geometry.
3. Structured JSON Medium High (45m) Gemma 4 natively supports schema-constrained output. Reliable, provided the schema asks for normalized room bounds (0–1000) rather than infinite floating-point vertex coordinates.
4. Geometric Healing High Medium (1h) Model coordinates will have minor jitter. A lightweight TypeScript snapping function must snap neighboring edges within tolerance ε to prevent visual tears in the 3D model.
5. 3D Generation Very High Critical Risk (1.5h) Extruding arbitrary non-convex polygons in Three.js often fails earcut triangulation. CSG boolean subtraction for doors/windows must be completely eliminated.
6. R3F Visualization Medium High (1.2h) React Three Fiber + Drei makes rendering lights, materials, OrbitControls, and camera presets straightforward and visually compelling.
7. Fallback Mode Low High (30m) Essential for hackathon survival. 2 pre-baked plans with cached JSON guarantee zero demo failure during judges' review.

2 Gemma 4 Verification & Constraints

Verified Capabilities vs. Practical Constraints:
  • Model Identifiers: gemma-4-31b-it (Flagship dense instruction-tuned model, superior reasoning and vision understanding) or gemma-4-26b-a4b-it (MoE variant, lower latency).
  • API Endpoint & SDK: Accessible via Google AI Studio REST endpoint (https://generativelanguage.googleapis.com/v1beta/models/...) or the official @google/genai Node/TypeScript SDK.
  • Multimodal Support: Verified. Gemma 4 natively accepts images and text prompts simultaneously across variable aspect ratios.
  • Structured Output: Supported using response_mime_type: "application/json" and response_schema. Gemma 4's internal thinking blocks are automatically handled by the SDK, returning strict, validated JSON.
  • Latency & Quota Warning: Image comprehension with structured output typically takes 10 to 22 seconds. A phased frontend progress bar ("Analyzing architectural layout...", "Snapping room boundaries...", "Generating 3D dollhouse...") is required to prevent judges from assuming the app has frozen.
  • Security: API keys must never be exposed on the frontend client. All AI requests must route through a server-side handler (e.g., /api/parse-plan).

3 Reality Check on 3D Reconstruction: The Architectural Trap

THE FATAL PITFALL: Vector Line Segment Tracing & Boolean CSG

Attempting to prompt a vision model for raw wall lines [[x1, y1], [x2, y2]] followed by Three.js CSG boolean operations (cutting holes in walls for doors/windows) will break. Unclosed wall intersections cause triangulation failures, and CSG booleans frequently crash the WebGL canvas on coplanar geometry.

THE WINNING PATTERN: Semantic Room-Box Partitioning

Constrain Gemma 4 to output Normalized Room Bounding Boxes (0–1000) with architectural tags: 

{
  "building": { "aspect_ratio": 1.33, "total_floors": 1 },
  "rooms": [
    { "id": "r1", "name": "Master Bedroom", "type": "bedroom", "bounds": { "x": 0, "y": 0, "w": 450, "h": 500 } },
    { "id": "r2", "name": "Living Room", "type": "living", "bounds": { "x": 450, "y": 0, "w": 550, "h": 700 } },
    { "id": "r3", "name": "Kitchen", "type": "kitchen", "bounds": { "x": 0, "y": 500, "w": 450, "h": 500 } }
  ]
}

Procedural Generation: Floors are extruded boxes colored by room type (wood for bedrooms, tile for bathrooms). Walls are generated automatically along perimeter edges and shared room boundaries. This guarantees 100% manifold, clean geometry with zero WebGL crashes.

OpenCV Reality Check: Do NOT build a custom OpenCV line-detection pipeline. Filtering CAD hatchings, dimension arrows, and furniture symbols requires days of algorithmic tuning. Rely on Gemma 4 for perception and TypeScript for deterministic 3D construction.

5 Recommended Architecture & System Flow

[Client: Next.js + React Three Fiber]
    ↓ (1) User drops floor plan image
[API: /api/parse-plan (Server Route)]
    ↓ (2) Base64 image + Structured Schema Prompt
[Google AI Studio: Gemma 4 31B (gemma-4-31b-it)]
    ↓ (3) Strict JSON (Normalized Room Bounding Boxes)
[Zod Validation & Snapping Utility (TypeScript)]
    ↓ (4) Validated Layout (Fallback triggered if invalid)
[Procedural 3D Dollhouse Engine (Three.js)]
    ↓ (5) Interactive 3D Model Rendered in Viewport

6 Top 5 Project Risks & 15-Minute Feasibility Tests

Rank Risk Description Severity 15-Minute Validation Experiment
#1 Gemma 4 Spatial Drift: Output boxes overlap awkwardly or hallucinate outside the boundary. High / Fatal Test 1: Run a standalone test script passing 1 floor plan to gemma-4-31b-it. Verify room coordinates are proportional and within 0–1000.
#2 Three.js Geometry Crash: Malformed polygon loops crash WebGL triangulation. High / Fatal Test 2: Build the 3D procedural generator first with mock JSON before connecting AI. Verify error-free rendering.
#3 API Latency / Rate Limits: Model takes >25s or returns 429 during live judging. Med / High Test 3: Build an instant 1-click "Demo Preset" toggle in the header that loads pre-baked JSON instantly if the API lags.
#4 Time Sink on OpenCV: Burning 3 hours writing custom computer-vision filters. High / Fatal Test 4: Ban OpenCV from the core pipeline. Rely purely on multimodal Gemma 4 for vision perception.
#5 Unfocused UI: Spending time on complex dashboards instead of the 3D viewer. Low / Med Test 5: Standardize on a clean split-screen layout (Left: Upload & Room Info; Right: Fullscreen 3D Canvas).
